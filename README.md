# NodeJS-Assignment2

A collection of 5 beginner-friendly Node.js HTTP server assignments created using basic Node.js concepts.

## Assignments

1. **Basic HTTP Server**
2. **HTML Response Server**
3. **Student JSON API**
4. **Route Handling Server**
5. **Personal Portfolio Server**

## Concepts Used

* Node.js

* Routing
* HTML Response
* JSON
* `fs` module
* `res.end()`

## How to Run

Open the required assignment folder in the terminal and run:

```bash
node server.js
```

Then open the server in your browser:

```text
http://localhost:4000
```

For route-based assignments, use the required routes such as:

```text
http://localhost:4000/about
http://localhost:4000/student
http://localhost:4000/projects
```
